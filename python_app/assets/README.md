# Assets Directory

This directory contains assets for the Camelot Python application.

## Directory Structure

- `icon.png` - Application icon (recommended size: 512x512)
- `presplash.png` - Splash screen image for mobile builds
- `images/` - Additional images used in the application
- `sounds/` - Audio files (if needed)

## Icon Requirements

For best cross-platform compatibility:
- **Desktop**: 256x256 or 512x512 PNG
- **Android**: Various sizes required (auto-generated by buildozer)
- **Format**: PNG with transparency support

## Adding Assets

Place your assets in this directory and reference them in your Python code using relative paths from the application root.

Example:
```python
from kivy.core.image import Image as CoreImage

# Load an image
image = CoreImage('python_app/assets/icon.png')
```
